# Hermes 出题专用清单：从决策错误到患者场景与压力实验

依据：用户对习题集制作的补充要求。对应 [总任务清单 H00–H46](clinical-benchmark-hermes-tasks-v0.1.md) 修订 0.2；结构化要求见 [出题合同 JSON](question-authoring-contract-v0.1.json)。本页细化原任务，不另设一套执行编号。

**Hermes 要实际制作场景、实验和题卡。先完成全患者旅程的覆盖地图，再把脑卒中首批选定错误的实验链做完整。全图有计划、首批已出题、医学已审核、模型已测试分别报告。**

## 直接执行这段指令

> 读取总任务清单和本页，核对本地工作及源提交后，依次完成：患者阶段目录与决策节点 → 节点/交接错误与原因假设 → 多对多覆盖矩阵 → 选定失败假设 → 基线场景及节点判据 → 对照实验 → L0–L3 压力实例。第一批聚焦脑卒中相关患者咨询的首次症状与就医决策，选择 2–3 个高价值失败假设及 1–2 条压力轴。交付五份实际填写的设计产物、可重建题卡、差异清单与审核材料，不只写方案或空模板。先完成可自主推进的工程和出题工作；节点与医学适用条件获真实审核后，再交 A/B 独立评分。不得代签或编造模型成绩。

实际先后顺序为：`H00 → H01/H02/H03 → H04 → H05/H06 → H10 → H12 → H07 → H08 → H09 → H11/H13/H14 → H15 → H21`。斜线表示按依赖分别推进，不表示必须调用多个代理；H02 仍依赖 H01。H16–H20、H25 在各自依赖满足时准备。

## 2. 从决策功能节点逐一寻找错误

下表是供 Hermes 展开的初始候选目录，**不是已观测到的模型缺陷，也不是已完成的错误分类**。每行的例子应拆成可观察、可复核的原子错误；例如升级不足和过度升级不能合并成一个含糊标签。

`decision_step_id`（D01–D12）指决策功能；`dialogue_node_id` 指某场景的多轮信息窗口或状态。一个对话窗口可能涉及多个决策功能，一个功能也可能跨多轮出现。

| 节点 | 可观察错误候选 | 策略原因假设 | 算法原因假设 | 工程原因假设 |
|---|---|---|---|---|
| D01 对象、意图与当前阶段 | 把代问者当患者；没有确认当前是在求解释还是执行建议 | 未确认对象就套用默认流程 | 对象/意图分类或路由错误 | 会话角色、患者 ID 或阶段字段错配 |
| D02 事实提取与结构化 | 漏掉症状、时间、药物或数值条件 | 过早摘要并丢弃关键细节 | 实体、单位、时间关系解析错误 | 消息截断、字段映射或输入丢失 |
| D03 否定、未知、猜测与更正 | 把“不知道”当“没有”；把患者猜测当事实 | 默认补齐缺失条件 | 否定范围、模态或指代解析错误 | null 被默认值覆盖，否定/更正标记未传递 |
| D04 来源与证据适用性 | 混淆来源，或不论情境一律服从某类来源 | 按权威标签代替证据核验 | 来源可信度、时效或权重计算不当 | 证据 ID 关联错误，引用或来源元数据丢失 |
| D05 缺失信息与追问选择 | 漏必要追问或反复问无关信息 | 先问全表再处理当前风险 | 问题价值排序、重复检测或停止阈值不当 | 已问/已答状态未保存，问答匹配漏失 |
| D06 竞争解释与因果判断 | 过早锁定；将先后发生说成因果 | 偏好单一解释，不寻找能推翻它的信息 | 候选排序、因果比较或不确定性估计不当 | 候选列表、比较输入或工具证据漏传 |
| D07 新旧证据整合与更新 | 承认新信息却继续依据旧条件给建议 | 为了保持一致而拒绝合理修正 | 旧证据权重过高或更新机制失效 | 仍读取旧状态、旧风险值或缓存 |
| D08 风险分层与行动时机 | 风险升级不足、过度升级或错过行动机会 | 一律安慰或一律升级 | 风险映射、阈值或时限计算不当 | 时间单位/时区/状态时钟错误或行动触发器未执行 |
| D09 处置选择与升级路径 | 建议和已识别风险不一致；安排不可执行 | 迎合患者偏好而撤回必要行动 | 行动排序、约束满足或资源匹配不当 | 处置模板取错、工具调用失败却标成功 |
| D10 医嘱理解与执行支持 | 遗漏条件、错误转述，或自行补成新的治疗安排 | 以通用建议替代核对原医嘱和理解 | 条件、频率、适用范围或任务拆解错误 | 版本陈旧、单位转换、转录或报告绑定错误 |
| D11 执行反馈、工具与交接 | 忽视障碍；未确认执行结果；交接丢关键信息 | 发出建议即视为问题解决 | 依赖调度、重试或升级选择不当 | 请求未送达、失败状态遗漏、重复操作或串病例 |
| D12 纵向随访、复发与合理结束 | 套用旧发作；遗漏变化；错误结束或无休止追问 | 把过去有效当作本次必然有效 | 纵向事件对齐、变化检测或终止判断不当 | 不同发作被合并、历史窗口丢失或状态未清理 |

每个节点另外检查输入与输出之间的交接：信息有没有实际进入下一节点、ID 是否仍指向同一患者和同一发作、否定/未知/来源/时间是否被保留、新证据有没有替代或修订旧状态。特别加入“上一环识别正确、下一环仍使用旧值”的对照。

为每个原子错误写出：`error_id`、所属 D 节点/交接、可观察行为、最小触发条件、合理反例、患者后果候选、原因假设、识别实验、反证、证据充分性和未决原因。每个节点都审阅策略、算法、工程三层；不适用或无法识别时说明，不能为凑三层硬编原因。

同一错误可以有多个原因假设。例如“没有依据更正后的时间更新建议”可能来自原则上固守旧结论、更新机制不当，也可能只是更正根本没传到模型。闭源模型没有足够内部证据时，报告行为失误与待验证原因，不能把它直接写成算法缺陷。

工程责任必须区分 `target_system`（被测系统）、`patient_simulator`（患者模拟器）、`provider_transport`（调用传输）和 `evaluation_judge`（评测/评分器）。模拟器给错信息不是模型独立医学失败。

## 3. 用患者阶段组织适用场景，不把错误互斥分箱

| 阶段 | 重点任务/错误候选 | 优先决策功能 | 首轮安排 |
|---|---|---|---|
| J01 看病前首次症状咨询 | 信息不足、关键追问、过早安心/诊断 | D01、D02、D03、D05、D06、D08 | 首批优先 |
| J02 就医决策与分诊 | 行动时机、就医升级、过度分诊与执行障碍 | D05、D08、D09、D11 | 首批优先 |
| J03 检查与报告解释 | 单位/参考条件、跨报告比较、证据冲突 | D02、D03、D04、D06、D07 | 先登记场景；M3 扩展 |
| J04 医嘱理解与核验 | 条件遗漏、错误转述、原医嘱版本与新事实冲突 | D01、D03、D04、D07、D10 | 先登记场景；M3 扩展 |
| J05 治疗与用药执行 | 信息不全仍补具体安排、执行困难、重复或错误落实 | D03、D05、D09、D10、D11 | 先登记场景；M3 扩展 |
| J06 用药后效果或不适咨询 | 效果解释、时间与因果混淆、变化后是否重评 | D02、D04、D06、D07、D08、D12 | 先登记场景；M3 扩展 |
| J07 治疗无效或病情恶化 | 固守旧判断、忽略新证据、升级不足 | D04、D05、D07、D08、D09、D12 | 先登记场景；M3 扩展 |
| J08 复发与长期随访 | 旧诊断套用、不同发作混淆、纵向状态与合理结束 | D01、D03、D04、D07、D08、D12 | 先登记场景；M3 扩展 |

这些阶段可重叠：分诊可能发生在看病前或就医途中，医嘱理解可能发生在出院之后。阶段标签用于说明患者任务，不强制按照医院空间划分。

第一轮 H04 要对八类阶段分别登记候选任务和覆盖缺口。每个适用的“阶段—节点—原子错误”组合，绑定场景或明确计划；暂不适用的组合写理由，缺医学依据的组合标待审。不要将所有节点、阶段、原因和压力机械全排列成题，也不要直接跳过难以分类的组合。

覆盖矩阵至少分开记录：

- **适用性**：适用、不适用、待确认；附理由和审核状态。
- **制作状态**：未计划、计划中、草稿、已生成实例。
- **临床状态**：未审核、存在阻断、获审；绑定版本。
- **工程状态**：未运行、失败、实际验证通过；附证据。
- **独立评分状态**：待分发、待填写、已填、争议未决、已裁定。

不能把临床待审题记成已准入，不能用“没有模型错误”填补没有题或没有运行的格子。覆盖率只对事先声明的范围与适用组合计算，分母、不适用项和未决项一起报告。

## 4. 先写真实可读的基线场景，再设计实验

H10 必须实际填写首批场景卡，不只列文件名。每卡包括以下内容：

| 部分 | 必须填什么 |
|---|---|
| 身份与目的 | 场景/病例/家族 ID，患者阶段，D 功能节点，目标错误和失败假设 |
| 患者原话 | 自然的首问及合法追问响应；不直接告诉模型要考哪种错误 |
| 固定事实 | 病例世界事实、患者知道的事实、首轮已见事实、未知/阴性/猜测、更正历史 |
| 来源与语境 | 人群、地区、证据来源、时间、既往意见或医嘱的实际内容和条件 |
| 对话路径 | 可触发披露、事件前提、允许跳过/重叠、障碍、合理结束、未匹配问法处理 |
| 节点判据 | 当时接受什么追问/行动、禁止什么结论、行动时限、什么新证据要求更新 |
| 可测性 | 目标行为在哪里能被观察，哪些路径没有观察机会，哪些是环境失效 |
| 实验接口 | 哪些字段允许改变、哪些必须不变；分组与压力定义后回填对应 ID |
| 审核与曝光 | 医学审核、来源许可、公开开发/校准/未曝光状态、版本与摘要 |

H12 在基线场景上先写临床 Oracle（按当前证据定义可接受行为的裁决系统）草稿，随后 H08/H09 逐组核对允许行为是否应变化。H15 对基线、关键对照、压力等级和低风险控制统一作真实适用性审核。不得从作者标准回答倒推这些规则。

全旅程场景概要可先行，但脑卒中首次咨询不应强行串入缺乏临床依据的用药—复发剧情。后续阶段可以使用独立病例或新的家族；只有事实与时间关系成立时才构成连续患者旅程。

## 5. 每个错误选择合适的实验分组

每个实验至少写出一个明确对比：比较目标、操纵变量、不变条件、允许行为应变/不变关系、观测指标、统计单位、至少三个竞争解释及其排查办法。并不是每个错误都需要下表所有分组。

| 分组方式 | 适合检验什么 | 必须防止的误判 |
|---|---|---|
| 基线与单因素表述/干扰 | 事实不变时判断是否稳定 | 同时改变语言、长度、病例事实却归因于一种干扰 |
| 关键临床条件配对 | 是否真正根据决定处置的条件调整 | 用同一个标准答案要求两组都一样；混入不受控病情差异 |
| 完整/部分披露及问法路径对照 | 是否主动获取有决策价值的信息 | 必要事实从未有合法获取途径，却要求模型知道 |
| 来源与既往意见对照 | 是否错误锚定、如何使用来源 | 同时改变意见内容和来源后声称只测权威偏好 |
| 更新与不更新对照 | 是否有选择地响应新证据 | 要求模型遇到任何追加信息都改变结论，或因为更正就判前后矛盾 |
| 受控工程故障对照 | 状态、字段、工具或缓存怎样影响结果 | 将评测环境故障记为模型能力失败，或把人为注入当真实发现 |

长度相关实验可使用原病例、无关追加、等长度相关追加、中性追加，但必须分别验证证据量、可读性和任务要求。“相关追加”可能真的增加临床信息，不自动构成纯长度对照。

既往意见实验可以分别改变内容和来源：先用同一来源比较支持/冲突/不确定意见，再在内容尽量相同的条件下比较来源。每组是否临床合理、是否应引起行动改变，由独立适用性审核决定。

每个首批目标错误都必须有合理反例：允许的追问、合理更新、谨慎但有用的表达，或能区分一律急诊与有效分诊的较低风险对照。低风险控制应有自己的真实病例条件与审核；若需引入另一临床背景，独立计数并声明，不能只把高风险病例换个安慰性描述。

## 6. 最后将压力梯度挂到已定义的对照实验

首批只实现 1–2 条最相关压力轴。信息缺失、噪声、无关信息、冲突证据、时序长度、更正、表述、多任务和工具/工程压力均进入目录，其他轴明确归后续批次。

| 等级 | 操作要求 | 审核重点 |
|---|---|---|
| L0 | 清楚、可获取必要信息，无额外目标干扰 | 基线是否可回答，判据是否认可合理路线 |
| L1 | 对选定轴做一次有限变化 | 除目标变量外是否保持条件一致 |
| L2 | 沿同一轴增加预定义操作量 | 是否混入语言、信息量或临床条件变化 |
| L3 | 进一步增加同轴压力，仍有合法的可接受决策路径 | 是否已变成无法完成目标任务；是否误罚不可见信息 |

每一级要写操作量、差异清单、文本长度/语言复杂度、关键事实及可获取机会、行动集合、作废条件和独立审核依据。压力顺序依据这些定义，不依据模型分数。

对“无关叙述”轴，优先保持临床事实、披露位置或匹配位置规则一致，只增加指定无关内容；若要测位置本身，另开实验。对“信息缺失”轴，允许行为可能转向追问或有条件建议，必须按该级实际可见信息更新判据，不能让模型猜隐藏答案。

对同时考察两条压力轴的组合，先获得单轴结果，再声明交互实验与分析方法；不要把多因素混合当作更高一级的单轴压力。

## 7. 首批脑卒中出题工作包

首批参考家族仍是急性脑卒中相关患者咨询，优先 J01/J02。下表是候选失败假设，用于引导出题；具体医学内容、行动时限和严重性仍须来源核验及临床审核。

| 候选假设 | 决策环节 | 场景设计方向 | 基本对照 | 首选压力轴 |
|---|---|---|---|---|
| 关键时间信息含糊时，模型未经确认便把它当作确定事实使用 | D02/D03/D05 | 患者对某项有决策意义的时间信息表达不同确定程度 | 明确、含糊、明确不知道；可通过合法追问澄清/无法获知分开 | 信息明确程度；不同条件各有允许行为 |
| 新信息足以改变原先判断时，模型仍被既往意见带偏 | D04/D07/D08 | 患者带有既往意见，之后实际披露新的关键事实 | 意见内容/来源控制；应更新与不必更新的追加证据 | 既往意见的重复干扰，或单独的叙述噪声 |
| 已具备获审行动依据时，模型仍把不必要补问置于行动之前 | D05/D08/D09 | 患者继续补次要信息或提出执行障碍 | 合理并行追问、无谓追问、真实行动障碍分别对照 | 无关叙述负担；执行障碍作为独立实验变量 |

## 9. 两层完整性与后续出题顺序

**全范围地图完整**：声明范围内的决策功能、交接、患者阶段和错误候选都有去向；遗漏、未审和不适用有理由。它表示规划可审计，不表示已找尽所有可能错误。
