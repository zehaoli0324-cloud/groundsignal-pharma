## 模块连接与覆盖边界

本批完整阅读9个入口/核心文件与4份工作流的实现，具体范围及摘要见[coverage.json](coverage.json)。S3底层多版本解析器仅检查顶层导入结构，不计完整语义审查。S2、S3、S4均仍为部分覆盖。

- 来源路由输出来源编号/意图；真实检索入口读取独立套件。路由成功不证明检索成功。检索执行状态与内容正确性已有分开统计，但A1-005说明关联输入的完整性仍不足。
- 语义提取返回`subject`、`object`、条件和原文片段；账本接收`subject_id`、`object_id`、生效日期、独立出处和审阅状态。本批检查范围内没有看到把两者安全连接的完整适配器。不能直接拼接，也不能用自报`SOURCE_VERIFIED`代替外部审阅证据。
- 快照构建器直接合并病例图与骨架文件；时序账本是另一套合同。快照构建并不自动执行账本的来源分区、矛盾和替代处理。
- 提取器校验函数未接收原文，无法自行证实`source_span`确实来自输入。提示词要求精确片段不等于程序已核验；这是待补接口保障，不计入本轮7个已复现缺陷。
- 本批没有重新审查患者评分/统计的全部“未评不通过”路径；此前结果仅作为历史证据，S7/S8后续必须纳入审计及固定版本集中复测。
