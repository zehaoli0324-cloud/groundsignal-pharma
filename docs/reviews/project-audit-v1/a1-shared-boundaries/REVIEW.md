## 隐私与公开输出

隐私扫描只返回类别、原文位置和待复核标记；零命中不表示可以公开。重叠替换区间被拒绝，替换映射含原值只能留在本地。原文审阅要求对照不可变输入；隐私确认需要覆盖所有原文回合。公开阻断清单使用受限字段，不包含患者原文、评审理由、评审姓名、来源会话编号和本地路径；合成哨兵测试验证了这些字段不进入投影。
