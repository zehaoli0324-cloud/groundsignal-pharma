# 临床安全边界（Clinical Safety Boundaries）

**本仓库是研究/情报系统，不是临床决策支持系统。不提供患者个体诊断、用药或剂量建议。**

医药情报与半导体情报最大的区别：**错误的"事实升级"可能带来真实的医疗风险**。以下纪律是医药版反幻觉铁律，任何入库、扫描、报告都必须遵守。

## 铁律（七条）

1. **阳性试验结果 ≠ 获批。** 一个 III 期试验达到主要终点，只能支持"疗效数据阳性"这一 claim；获批必须由监管机构（FDA/NMPA/EMA）的批准记录支持。两者分列，禁止从前者推断后者。
2. **试验注册 ≠ 疗效。** ClinicalTrials.gov 记录（NCT ID）只证明"试验存在、状态如何、入组什么人群"；注册记录不能支撑"这个药有效"。注册 ≠ 证据强度。
3. **不良反应报告 ≠ 因果。** openFDA/FAERS 的不良事件报告是"信号发现"来源，不建立因果或发生率。安全信号必须保留：来源、分母/背景（已知时）、不确定性。
4. **单一资产 ≠ 类别效应。** 一个 GLP-1 药物的安全性事件，不能在没有显式证据时推广为"GLP-1 类别效应"。跨资产推断（SAFETY_ANALOG）只能作为 HYPOTHESIS，且必须说明依据。
5. **公司声明与同行评审/监管结论分离。** 药企新闻稿（"我们相信/有望成为 best-in-class"）是 Tier 2 一手来源，不能升级为 VERIFIED 事实。官方批准日期以 FDA/NMPA 为准。
6. **矛盾证据并存，不折叠成单一"真相"。** 一个试验终止而另一个同靶点试验推进，两条 claim 都要保留，标注 SUPERSEDED / PENDING_VERIFICATION，而不是删掉旧记录。
7. **高危监管/安全事件必须显式复核。** CLINICAL_HOLD（临床暂停）、CRL（完全回复函）、BOXED_WARNING_UPDATE（黑框警告）、PROGRAM_DISCONTINUATION（项目终止）四类事件，在自动影响传播升级到 HYPOTHESIS 以上之前，必须人工/Agent 显式复核。

## 证据分级（医药版）

| Tier | 来源 | 能支持什么 |
|------|------|-----------|
| Tier 0 | FDA Drugs@FDA / 批准记录、ClinicalTrials.gov、EMA、NMPA/CDE | 获批状态、试验状态、监管事件 |
| Tier 1 | PubMed 同行评审文献、版本化专业指南 | 疗效/安全/机制结论（保留研究设计边界） |
| Tier 2 | 公司官网/年报/新闻稿/交易所披露 | 管线、交易、产能（不得静默覆盖监管/注册记录） |
| Tier 3 | 高质量医学/财经媒体 | 事件发现与背景（不升级为 VERIFIED） |
| Tier 4 | 论坛/社交媒体/无来源摘要 | 仅线索（LEAD），不能直接支撑生产级 claim |

**source quality ≠ evidence strength**：顶级期刊可以报告探索性生物标志物关联，但那不把关联变成已验证的预测性生物标志物。

## 落地检查（入库完成标准追加项）

- [ ] 没有把"阳性结果"写成"获批"
- [ ] 没有把 NCT 注册状态写成疗效证据
- [ ] 安全信号带来源 + 不确定性标注
- [ ] 跨资产推断标为 HYPOTHESIS 而非事实
- [ ] 高危事件（CLINICAL_HOLD/CRL/黑框警告/项目终止）已显式复核
