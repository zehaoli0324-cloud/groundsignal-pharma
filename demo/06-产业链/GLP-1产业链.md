# GLP-1 产业链

**减重药市场爆发，核心瓶颈在原料药（API）与制剂产能。**

```text
GLP-1 多肽 API → 制剂灌装 → 药企商业化 → 渠道/患者
      ▲              ▲
   多肽 CDMO       Catalent 等灌装厂
```

## 关键玩家

- 原研：礼来（替尔泊肽）· 诺和诺德（司美格鲁肽）
- 国产：[[信达生物]]（玛仕度肽）
- CDMO：[[药明康德]] · [[药明生物]]
- 靶点：GLP-1R · GIPR · GCGR

## 关键约束

- 产能：GLP-1-API-产能（诺和诺德收购 Catalent、礼来 53 亿美元扩产）
- 口服剂型生物利用度低 → API 需求倍增
