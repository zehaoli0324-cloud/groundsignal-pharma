# DeepSeek — case-003-licensing-bd__BASE (twin run)

2026-08-27

## Prompt

> Asset Y 要做 ex-China licensing。我们只能先和两家公司进入实质沟通。  
> **A、B、C 你选哪两家？哪一家看起来最强但其实最可能浪费我们的时间？为什么？你最想在 outreach 前补哪一条信息？**

## Evidence

#### Asset Y
- Target T ADC，Phase II。
- 希望保留中国权益。
- 需要海外 pivotal development + commercialization。

#### Company A
- 全球肿瘤商业化能力极强。
- 自研同 Target T Phase III。
- ADC 经验强。
- 多笔大型 licensing。
- 交易谈判能力强。

#### Company B
- 无 Target T 内部资产。
- 有同适应症 franchise。
- 过去 3 年持续 in-license ADC。
- 有 ex-China / co-development precedent。
- 商业化能力中上。

#### Company C
- 现金多。
- oncology footprint 较弱。
- 无成熟 ADC 平台。
- licensing appetite 不明确。

## Output 要求

必须给：
- Top 2；
- “最容易浪费时间”的对象；
- 1 个最高价值 diligence question。

## Answer

**Top 2：A 和 B**  
**最容易浪费时间：A**  
**最高价值 diligence question：**  
“如果我们的 Phase II 数据在关键亚组（如低表达/耐药人群）与你们自研的 Phase III 资产出现疗效差异，你们是否愿意接受基于联合用药或序贯治疗的共同开发框架，而不是坚持资产收购或终止谈判？”

---

### 详细逻辑

#### 1. 为什么选 A 和 B（而不是 C）
- **A**：全球肿瘤商业化能力极强 + ADC 经验 + 多笔大型 licensing，意味着它有足够的资源和渠道把 Asset Y 的海外价值最大化。你保留中国权益，它拿海外，结构上互补。
- **B**：无 Target T 内部资产（无直接竞争冲突），但有同适应症 franchise（意味着它理解市场、有现成销售队伍和 KOL 网络），且过去 3 年持续 in-license ADC（证明它有明确的 ADC 战略意图和执行力），还有 ex-China / co-development precedent（说明它愿意接受非全权收购的灵活结构）。
- **C**：现金多但 oncology footprint 弱、无 ADC 平台、licensing appetite 不明确。这意味着即使它有钱，也可能没有能力或意愿做 pivotal development + commercialization。它更像“财务投资者”而非“战略伙伴”，对 Phase II 资产来说，战略伙伴的价值远高于现金。

#### 2. 为什么 A 看起来最强，但最可能浪费你的时间
- **看起来最强**：全球商业化能力 + 自研同靶点 Phase III + ADC 经验 + 大型 licensing 记录，这几乎是完美的“买家画像”。
- **但最危险**：**它有自己的同靶点 Phase III 资产**。这是核心矛盾。
  - **竞争性冲突**：Asset Y 是 Target T ADC，A 的自研资产也是 Target T（且 Phase III 更后期）。A 的动机很可能是“买下你，然后雪藏或终止你的项目，以保护自己的管线”。即使它不这么做，它也一定会要求你提供全部临床数据、生物标志物、CMC 细节，用于评估“是否对自己的资产构成威胁”——这个过程会消耗你大量时间和数据，但最终它可能以“数据不足以支持差异化”为由退出，或者提出极低的收购价。
  - **谈判地位不对等**：A 的谈判能力强，且它知道你只有 Phase II 数据，而它有 Phase III 数据。它完全可以用“我们的数据更好”来压价，或者要求你接受“以 A 的资产为主导，Asset Y 作为辅助”的结构，这会让你失去对 Asset Y 的控制权。
  - **时间成本**：大型 licensing 谈判周期通常 6-12 个月，而 A 内部有同靶点项目，它的法务、临床、商业团队会反复交叉审查，决策链极长。你很可能在 6 个月后收到“我们决定不推进”的回复，而这时 B 可能已经找到了其他合作伙伴。

#### 3. 为什么 B 是更稳妥的第二选择
- **无直接竞争**：B 没有 Target T 内部资产，所以它没有“保护自家管线”的动机，更可能真心想推进 Asset Y。
- **有同适应症 franchise**：它知道这个适应症的市场、患者流、KOL 关系，能快速启动 pivotal 设计。
- **持续 in-license ADC**：说明它的战略是“外部创新 + 内部商业化”，它需要 Asset Y 来补足管线，而不是消灭它。
- **有 co-development precedent**：这意味着它接受“你保留中国权益，它做海外”的灵活结构，谈判阻力更小。

#### 4. 为什么 C 直接排除
- 没有 ADC 平台，意味着它无法有效评估 Asset Y 的技术风险，也无法在临床开发中提供技术指导。
- oncology footprint 弱，意味着它即使拿到海外权益，也可能找不到合适的 CRO、KOL、监管路径。
- licensing appetite 不明确，意味着你可能要花大量时间教育它“为什么这个资产值得买”，而它最终可能因为内部战略不清晰而放弃。

---

### 最高价值 diligence question 的解析

**问题**：“如果我们的 Phase II 数据在关键亚组（如低表达/耐药人群）与你们自研的 Phase III 资产出现疗效差异，你们是否愿意接受基于联合用药或序贯治疗的共同开发框架，而不是坚持资产收购或终止谈判？”

**为什么这是最高价值**：
- 这个问题直接测试 A 的**真实意图**。如果 A 回答“我们只考虑收购”，那基本可以确认它是为了“消灭竞争”，你应立即止损。如果 A 回答“可以考虑联合开发”，说明它至少愿意在非竞争框架下合作，这时你才有继续谈的基础。
- 对于 B，这个问题同样有价值，因为它测试 B 是否愿意在“数据不完美”的情况下，通过灵活结构（如里程碑付款 + 共同开发）来分担风险，而不是要求你承担全部临床失败风险。
- 这个问题比“你们愿意付多少首付款”更有价值，因为首付款可以虚高，但**合作框架**决定了你能否保留中国权益、能否分享海外收益、能否在临床失败时保护你的数据资产。

**补充说明**：如果你只能补一条信息，不要问“你们预算多少”或“你们时间表如何”，那些都可以在谈判中调整。**“合作框架的灵活性”是决定这笔交易是“双赢”还是“单方吞并”的根本变量**。
