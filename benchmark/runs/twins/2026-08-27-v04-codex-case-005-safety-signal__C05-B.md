# Codex — case-005-safety-signal__C05-B (twin run)

2026-08-27

## Answer

最新信息使判断明显转向 **target-level 风险**，但暂时不应宣布为已证实的 class effect。

### 因果假设排序

1. **Target-level / on-target hepatotoxicity——当前首要假设**
   - S、A、B 三个不同 molecule、且 B 使用不同 modality，仍出现一致 hepatic signal。
   - 这削弱了“仅由 S/A 相似 linker 或 delivery chemistry 导致”的解释。
   - 多 modality 的一致性是 target-level hypothesis 上调的关键证据。
   - 但机制尚未验证、监管机构也没有 class-wide warning，因此置信度应为“中高”，而非确定。

2. **Platform/delivery-related toxicity——次要假设**
   - S 与 A 的相似 linker/delivery chemistry 仍可能解释二者风险，尤其是严重程度或暴露阈值。
   - 但无法单独解释不同 modality 的 B，除非三者存在共同的肝脏富集、代谢物或组织分布特征。

3. **各 molecule 独立的 off-target/idiosyncratic toxicity——进一步下调**
   - 三个同靶点资产独立产生方向一致的肝毒性，纯巧合的可能性下降。
   - 仍需排除不同分子各自的 reactive metabolite、免疫原性或制剂杂质问题。

### Negative control

**B 原先是最关键的 negative control，但现在已经失效，并转化为支持 target-level 风险的正证据。**

下一步需要重新建立两类 negative control：

- **同 platform、不同 target 的资产**：若没有类似肝毒性，反对 platform hypothesis。
- **同 target 但无有效 target engagement，或使用不进入肝脏的 modality/分子**：可区分 on-target toxicity 与单纯肝暴露或递送毒性。

健康人群背景发生率和 spontaneous reports 只能辅助校准，不能作为强 negative control，因为存在报告偏倚和暴露差异。

### Portfolio action

现在不应继续把 S 当作孤立 molecule failure：

- 将同靶点项目整体升级为 **潜在 class risk**，暂停新增大额投入及无保护性的快速扩展。
- 对 S/A/B 做统一的 hepatic safety review，按 target engagement、肝暴露和累计暴露重新分析，而不是分别解释。
- 对早期同靶点资产设置更高的继续开发门槛：必须证明可获得足够 therapeutic window，并采用强化肝功能监测、停药规则和高风险患者排除标准。
- 暂缓仅靠更换 linker 或 delivery“解决问题”的 follow-on 项目；如果风险是 on-target，这类优化可能只降低暴露，却不能消除机制性毒性。
- 若疗效差异化不足或替代靶点充足，应考虑降低整个 target franchise 的优先级；若疗效价值很高，则优先投资于限制肝脏 target engagement、间歇给药或组织选择性策略。

### 最有区分力的下一条证据

最有价值的是一套**跨资产、暴露匹配的 target-engagement–toxicity 分析**：

> 肝毒性是否随肝内 target engagement 或下游 pharmacodynamic effect 增强，并且这种关系跨 S、A、B 和不同 modality 保持一致？

- 若毒性与 target engagement/下游生物学一致相关，而与 linker、母药暴露或特异代谢物无关，强力支持 target-level causality。
- 若 S/A 与共同 linker、肝脏蓄积或相同代谢物相关，而 B 经复核后具有不同病因，则重新支持 platform hypothesis。
- 若三个资产呈现不同的病理、时间过程和生物标志物模式，“一致 signal”可能只是宽泛的 hepatic event 聚合，应回到 molecule-specific 判断。

实际执行上，应优先做病例级 adjudication，并统一比较 onset、剂量/暴露关系、去激发/再激发、肝活检模式、免疫特征、胆汁淤积与线粒体损伤标志物。**跨 modality 的共同 target-PD signature 与肝损伤共变**，是当前最能改变 portfolio 决策的证据。
