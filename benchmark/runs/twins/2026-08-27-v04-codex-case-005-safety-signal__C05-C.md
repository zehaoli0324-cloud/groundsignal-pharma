# Codex — case-005-safety-signal__C05-C (twin run)

2026-08-27

## Answer

当前最合理的归因排序是：**molecule-specific > platform/chemistry > target-mediated**。

1. **S 特异的 molecule/metabolite 风险——最高**
   - A 的肝毒性已证实来自特异 off-target metabolite，因此不能再作为“同 target 或相似 platform 导致肝毒性”的支持证据。
   - S 可能产生自身特异的反应性代谢物、线粒体毒性、胆汁酸转运抑制或免疫性肝损伤。
   - spontaneous report 支持 S 存在真实安全信号，但不能区分 molecule、platform 和 target。

2. **S 与 A 共享 linker/delivery chemistry 的 platform 风险——次高但明显下调**
   - 结构相似仍值得调查，但 A 的已知病因削弱了共因果推断。
   - 只有当 S 产生相同/相近毒性代谢物，或共同 chemistry 在相当暴露下呈现一致肝毒机制时，platform 归因才会上升。

3. **target-mediated class effect——最低**
   - **B 是关键 negative control**：同 target、较大暴露、不同 modality，却无同类 warning。
   - 加上没有监管机构的 class-wide warning，目前不支持 target-level 肝毒性。
   - 但若 B 的肝脏靶点覆盖不足、组织分布不同，或没有达到与 S 相同的持续 target engagement，其反证强度会下降。

### Portfolio action

- **暂停 S 的剂量升级和新增入组**，开展病例判定、暴露分析及风险控制；是否终止取决于可预测性、可监测性和治疗窗，而不是立刻清退整个 target。
- **不应因 S 自动停止 B 或其他不同 modality 的同靶点项目**；B 可继续，但加强肝功能监测。
- 对采用 S/A 类似 linker或 delivery chemistry 的资产做定向审查：代谢物谱、肝暴露和非临床肝毒性。现阶段适合设置阶段门槛，不宜直接清退整个平台。
- 新增同靶点项目优先选择不同 chemistry/modality，降低共同失效风险。

### 最有区分力的下一条证据

首选做**跨资产、暴露匹配的代谢物与机制比较**：

- 比较 S、A、B 在人肝细胞及临床样本中的代谢物谱；
- 确认 S 是否产生 A 的已知 off-target metabolite，或自身特异的反应性代谢物；
- 同时检测共价结合、线粒体功能、胆汁酸转运及细胞应激，并把结果与患者暴露和 hepatic event 对齐。

判读方式：

- **仅 S 出现毒性代谢物/效应** → 强支持 molecule-specific；
- **S 与其他共享 linker/delivery 的资产出现相同效应** → platform 风险上调；
- **不同 molecule和 modality 只要达到相当肝脏 target engagement 都出现损伤** → target 风险上调。

因此，最新信息使 **A 不再是 target/platform 的正向复制证据**；当前不应做 class-wide portfolio kill，重点应转向验证 S 的特异代谢与肝脏暴露机制。
