## Q1 Fact：Asset X 当前是什么开发状态？能否称“已上市竞品”？

**结论：Asset X 是 III 期、主要终点对安慰剂阳性的在研资产，不能称为“已上市竞品”。**

- **OBSERVED：** X 为 GLP-1R/GIPR 双激动剂，用于肥胖；已进入 III 期，主要终点相对 placebo 阳性，但尚未申报上市。
- **DERIVED：** X 已跨过重要临床验证节点，但仍处于上市前阶段。III 期阳性不等同于已提交、已获批或已商业化。
- **HYPOTHESIS：** X 具有成为上市竞争者的潜力，但其申报时间、监管结果和商业化能力均无法从现有 snapshot 判断，**证据不足**。

因此，准确表述应为：

> “处于 III 期且主要终点阳性的潜在上市竞争资产”，而不是“已上市竞品”。

## Q2 Relation：Asset X 与 Asset A 属于什么竞争关系？

**结论：A 是 X 当前最直接的竞争对象，兼具同机制 comparator、同适应证竞争者和已上市商业标杆三重属性。**

- **OBSERVED：** X 与 A 均为 GLP-1R/GIPR 双激动剂，均面向肥胖；A 已获批上市，X 尚未申报。
- **DERIVED：**
  - **机制关系：** 同机制资产，可视为最接近的机制 comparator。
  - **临床关系：** 同适应证，目标患者群高度重合。
  - **商业关系：** A 已经上市，X 若获批将进入由 A 已参与竞争的市场。
  - **时序关系：** A 具有先发优势；但其优势究竟体现为多少市场份额、医生认知或准入壁垒，snapshot 无法量化。
- **HYPOTHESIS：** A 可能成为 X 在研发定位、申报沟通及商业差异化上的首要参照，但具体竞争强度仍取决于 snapshot 未提供的疗效、安全性、价格、医保、供应和处方表现。

## Q3 Relation：为什么 Asset B 是市场竞争者，但不是完全同机制 comparator？

**结论：B 与 X 在患者和治疗选择层面竞争，但机制只能称为邻近，不能称为完全同机制。**

- **OBSERVED：** B 是已上市的肥胖治疗产品，为 GLP-1R 单激动剂；X 是 GLP-1R/GIPR 双激动剂。
- **DERIVED：**
  - **市场竞争：** 两者治疗同一疾病，可能争夺相同或相近患者、处方决策和支付资源。
  - **机制差异：** 两者都涉及 GLP-1R，但 X 还激动 GIPR，因此靶点构成并不相同。
  - **比较定位：** B 可作为治疗类别和市场层面的 comparator，但不是严格的同机制 comparator。
- **证据边界：** 不能仅因 X 是双激动剂、B 是单激动剂，就推断 X 的疗效或商业竞争力更强；snapshot 没有提供头对头数据。

## Q4 Evidence Sufficiency：能否说 Asset X 疗效优于 Asset A？

**结论：不能。现有证据只支持 X 对 placebo 达到主要终点，不支持 X 优于 A。**

- **OBSERVED：** X 的 III 期主要终点相对 placebo 阳性。
- **OBSERVED：** snapshot 明确不包含 X 与 A 的头对头数据。
- **DERIVED：** “对安慰剂有效”与“优于另一活性药物”是不同证据命题，前者不能推出后者。
- **证据不足：** snapshot 也未提供可用于可靠跨试验比较的具体效应量、入组人群、治疗周期、统计设计或安全性信息。

在会议材料中，最多可表述为：

> “X 已证明相对安慰剂达到 III 期主要终点；其相对 A 的疗效优势尚未建立。”

即使未来获得跨试验数值，若无可比设计，也应避免直接宣称优效。

**最可能改变整体结论的新增证据**是：X 与 A/B/C 的直接比较数据，以及各产品的安全性、标签、价格、医保、供应和真实处方表现。在这些信息出现前，竞争判断应保持“关系明确、强弱未完全量化”。
