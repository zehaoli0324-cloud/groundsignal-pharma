# 合成运行恢复合同 v0.1

R2实现了旧v0.2检查点的**只读恢复前检查**；R3另增v0.3合成运行格式和最小显式续跑。两者复用原运行器的配置构造、调度与会话校验，只接受合成开发病例。旧v0.2格式仍然不能续跑，也不会被静默迁移。

## 运行与预期

需要 Python 3.11或更新版本，无第三方依赖。在仓库根目录执行：

```bash
python -m scripts.patient_eval.recovery --drill-out medical/patient-eval/local/recovery-first
python -m unittest tests.patient_eval.test_recovery_preflight -v
python -m scripts.patient_eval.resumable_drill --out medical/patient-eval/local/resume-first
python -m unittest tests.patient_eval.test_resumable_study -v
```

第一个演练保留R2旧格式行为：预期保存1条、待执行1条；`consistency_passed=true` 只表示字段内部一致，`resume_allowed=false`。第二个演练使用R3新格式：故意中断后保存1条，再恢复剩余1条，8/8检查通过。已有目录会被拒绝，请保留首次结果，换新名称；不要清空后冒充首次成功。

供代码复用的入口为 `inspect_recovery(suite, client_config, out, repeats=1, seed=7)`。其中第二参数是公开配置字典，不是客户端，因此检查函数没有调用模型的入口。

## 本轮检查和处置

| 情况 | 检查或处理 |
| --- | --- |
| 输入、配置、策略/抽取器/分类器版本、重复次数、种子、调度顺序变化 | 与期望输入及现运行器配置逐项比较，不一致即报告拒绝原因 |
| 会话缺失、计数错误、身份或来源字段变化 | 核对连续编号、会话合同、场景、配置、响应状态与摘要清单 |
| 清单引用目录外路径或符号链接 | 拒绝；不会跟随清单指定的任意路径读取 |
| 已落盘但清单未登记的会话 | 视为孤立文件，拒绝自动接纳；保留原文件 |
| 未落盘结果、残留临时文件、意外汇总文件 | 不猜测是否完成、不删除、不重新执行；报告目录不一致 |
| 已完成运行 | 核对汇总和单会话一致性，待执行数为0，明确不重跑 |
| 已保存超时等失败会话 | 算作已保存记录，不算成功结果；不删除或自动重试 |
| 清单仍写“运行中” | 进程存活状态为未知，不能直接判断仍活着或已死亡 |

检查得到的文件摘要只是**本次观察值**，不是历史可信摘要。测试专门修改一段仍满足格式的合成回答：其内部一致性检查可以通过，但结果仍标记完整性未获证实、续跑不允许。不能把这个限制藏在“全部检查通过”背后。

旧v0.2检查点没有排他锁；R2只读结果不保证与并发写入隔离，只用于受控本地合成目录诊断，不能作为执行授权。R3的v0.3运行使用 `.study.lock` 排他锁覆盖核验、执行和写入；锁已存在时不猜测进程是否存活或锁是否过期，直接在任何新增调用前拒绝。受控的键盘中断会记录为 `interrupted` 并释放自己的锁；强制终止可能留下锁或 `running` 状态，需要人工处理，系统不会自动清除或推定为安全。

v0.3在每条会话清单中记录SHA-256（Secure Hash Algorithm 256-bit，256位安全散列算法）字节摘要，并绑定输入、公开配置、调度及相关代码文件摘要。恢复时逐条核验，已保存会话保持字节不变；失败会话也是已保存记录，不会因失败而自动删除或重试。摘要用于发现相对于清单的本地意外变化，不是独立信任根；若清单与文件同时被有意改写，系统不能据此证明真实性或临床可信。

## R3实现状态与仍保留的限制

1. 已实现：新运行显式声明v0.3可恢复格式，记录输入、配置、调度与相关代码摘要；旧v0.2格式不静默迁移。
2. 已实现：每个已保存会话在清单中绑定字节摘要，核验后才跳过；摘要不让病例或清单自证可信。
3. 已实现：排他锁覆盖检查和写入；不根据进程号或时间戳自动移除锁。受控中断与强制终止的边界已分开。
4. 已实现并通过合成演练：已完成会话字节不变，只调用剩余会话；失败记录保留，不自动洗掉。
5. 已明确：未落盘的进行中会话可能已发生调用，不承诺“恰好一次”；恢复尝试记录重放风险。当前仍只演练本地脚本。
6. 已实现：孤立会话、临时文件、摘要不匹配均在新增调用前拒绝，保留首个失败目录；不会删除异常文件来自动解锁。
7. 已实现：只捕获可处理的键盘中断并记录；不声称强制终止后也能可靠更新清单。

仍未实现：对残留锁或 `running` 状态的人工裁决命令、跨主机分布式锁、外部不可篡改摘要、真实接口的幂等键。当前本地合成续跑已经可用，但不能外推为真实平台恢复能力已验收。

本轮不改变真实来源准入、S5冻结证据或S6状态。用户的四项默认勾选原文件未修改。本人独立学习、另一人复现和双人评分仍待人工验收。
