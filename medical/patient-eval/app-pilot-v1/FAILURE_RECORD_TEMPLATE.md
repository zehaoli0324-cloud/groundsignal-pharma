# 失败记录（填写后保存在local目录）

- 记录编号／关联计划摘要／会话编号：
- 应用、版本、模式、日期与账户设置：
- 问题家族／基础或改编／自然或探查阶段：
- 用户原话、回合编号：
- 当轮已披露事实、仍未知事项：
- 产品回答原句、回合编号、截图：
- 违反判据、支持来源和适用条件：
- 行为错误类型（归属／否定／时间／数值／材料支持／过度结论／未更新／其他）：
- 可能影响、严重程度与待临床复核点：
- 采集或评分工程错误是否排除、依据：
- 根因假设、支持与反对证据、仍需什么内部日志：
- 基础题复测次数、全部结果、配置差异：
- 单因素变体及变化字段、全部结果：
- 研发处理人或团队、拟修改点、验收标准（未分配可留空）：
- 冻结回归题与新题表现、其他能力是否退化：
- 两名评审各自判断、分歧和最终复核记录：

对话能确认的行为与未证实的内部原因分开写。不得因复测通过删除首次失败；不得将合成题标作真实患者材料。
