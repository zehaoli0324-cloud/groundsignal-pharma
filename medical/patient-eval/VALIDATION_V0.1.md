审查中实际发现并修复了以下问题：

1. 固定前缀后额外补充信息仍可被当作同决策点比较：现在校验完整输入及精确回答数量。
2. 直接调用评分函数可能绕过审核人和无效原因检查：现在评分公共入口也执行会话校验。
3. 仅凭修复标签可能误判根因已验证：现在要求实际状态转移、最终输出一致，并重新计算机械检查；删除轨迹或替换错误回答会拒绝验证。
4. 多次纠正同时被丢弃可能被误写成单因素结论：本版故障夹具限制为一次最后轮的纠正，扩展需另实现逐因素控制。

测试还覆盖目标超时和响应结构错误保留分母、隐藏标注不进入模型输入、黑盒不能升级内部归因、单变量行为探针、跨协议/缺配对拒绝、家族等权统计及回答文本的网页转义。

未进行真实 API 调用、临床专家评分、小荷采集、动态患者模拟、完整十类故障验收或独立封存集测试。服务成功率和合成机械成绩均不能建立临床安全性。远程持续集成状态以本次合并请求的实际检查为准。
