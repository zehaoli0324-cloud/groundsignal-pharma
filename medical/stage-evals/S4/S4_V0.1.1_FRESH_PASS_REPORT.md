# S4 v0.1.1 — Independent Fresh Held-out First Run — PASS

> Stage: S4 — Medical Knowledge Graph Construction / Update  
> Implementation: `S4-truth-ledger-v0.1.1`  
> Evaluation mode: **independent fresh held-out, first observation**  
> Decision: **PASS — bounded S4 conditional release**

## 术语表

- **KG — Knowledge Graph（知识图谱）**：用实体、关系和带来源的事实边组织医学知识。
- **Fresh held-out（新鲜留出集）**：实现冻结后才创建、此前未参与开发的独立测试集。
- **Temporal frontier（时间前沿）**：同一语义槽位当前最新、仍具有决策意义的 `ACTIVE` 或未解决 `CONTESTED` 状态。
- **CONTESTED（争议态）**：同一槽位、同一有效时间存在互相冲突的事实，系统必须保留冲突而不是自动选边。
- **State invariant（状态不变量）**：无论具体测试题怎样变化，状态机始终必须满足的结构规则，例如不能同时存在过时的 `ACTIVE` 边。

## 2. What the new fresh suite tests

The 20 unseen trajectories test combinations not used as complete trajectories in the v0.1.1 development pass:

- five-version temporal replacement chains;
- unresolved contested frontiers followed by multiple late historical arrivals;
- conflict → resolution → new conflict → later resolution;
- four-way same-date contested-set closure;
- late duplicate provenance merges into superseded contested history;
- duplicate evidence on a current contested claim without reactivation;
- combined jurisdiction / population / condition scope isolation;
- interleaved independent subject histories;
- rollback through conflict resolution, contested-set growth and provenance merge;
- polarity conflict followed by later resolution;
- fail-closed provenance / review / S3 relation / partition gates;
- rejected-event state preservation.

In addition to case-specific expected outputs, the evaluator checks generic invariants after every step:

```text
one current frontier date per slot
<= 1 ACTIVE edge per slot
ACTIVE and CONTESTED cannot coexist in one current slot
CONTESTED current frontier must contain >= 2 edges
current CONTESTED edges form a complete symmetric conflict clique
conflict links cannot cross slot/date boundaries
SUPERSEDED edges must point to an existing in-slot non-backward successor
no duplicate claim + effective-date edge
no stale ACTIVE edge
```

## 4. Release interpretation

This fresh PASS independently validates the **controlled truth-ledger state-transition layer** against the current S4 contract. It is stronger than the previous exposed regression because the new trajectories were created only after v0.1.1 was frozen.

It does **not** establish:

- clinical correctness of real drug facts;
- production-scale persistent graph behavior;
- terminology/entity normalization;
- real-source ingestion quality;
- distributed/concurrent update correctness;
- unrestricted clinical deployment safety.

Therefore S4 moves from `FRESH FAIL / BLOCKED` to:

> **CONDITIONAL PASS — independently fresh-validated controlled truth-ledger state machine.**

Unrestricted production clinical auto-ingestion remains disabled. Downstream work may use the S4 controlled contract, but must not treat it as proof of real clinical graph correctness.
