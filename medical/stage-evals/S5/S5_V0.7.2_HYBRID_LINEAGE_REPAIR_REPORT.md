## 1. Why this version exists

S5 v0.7 independently exposed four hard-gate failures. Commit `62ef4a183c738293acd9b2267f870cf5fb290154`
added the deterministic v0.7.1 builder-side repair for F24 (cross-split exact semantic duplicate)
and F27 (Unicode NFKC-compatible identifier collision). F25 and F26 remained the algorithm-owned
blockers: paraphrased heldout-derived source laundering and partial protected-fragment reuse.

v0.7.2 integrates the first generic algorithm candidate and also makes the authenticated export
validator independently enforce the same lineage boundary. It does **not** create a new fresh suite.

## 2. Implementation

### Historical implementation preservation

The direct implementations are retained as versioned source blobs:

- `scripts/s5_trust_policy_v071.py` — exact v0.7.1 deterministic builder implementation.
- `scripts/s5_trust_policy_v061.py` — exact v0.6.1 pre-v0.7 builder implementation for exposed validator probes.
- `scripts/export_training_data_v061.py` — exact v0.6.1 exporter implementation.

Current entry points layer new checks over those preserved versions. This makes the repair auditable
without rewriting the historical implementation used by prior first observations.

### `s5-lineage-hybrid-v0.7.2`

The new detector uses only Python standard-library components and already-exposed/development data:

1. exact structured semantic-core fingerprint;
2. lexical/structural record similarity;
3. field-level similarity over patient/evidence/interaction/expected-behavior/graph/safety/scoring;
4. exact and near reuse of multiple high-signal fields;
5. span-level reuse evidence with source/reference paths;
6. explainable `ALLOW | REVIEW | BLOCK` output with nearest protected reference and reasons.

The policy builder rejects ordinary training sources classified `BLOCK` against protected
`heldout`/`regression` references. The exporter separately re-authenticates policy source bytes
and runs the same lineage rule, so a policy constructed by an older vulnerable builder cannot
bypass the training-export boundary.
