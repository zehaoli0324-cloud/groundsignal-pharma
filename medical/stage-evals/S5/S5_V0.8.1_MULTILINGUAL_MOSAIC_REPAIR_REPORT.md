# S5 v0.8.1 — Multilingual and Mosaic Exposed Repair

Status: **EXPOSED REPAIR PASS / NOT FRESH / RELEASE BLOCKED**

## 术语表

- **Multilingual lineage（多语言血缘）**：受保护案例被翻译后仍保留相同任务与决策约束。
- **Mosaic contamination（拼接污染）**：一个候选同时复用多个受保护案例的片段。
- **Review resolution（复核处置）**：风险为 `REVIEW` 时，系统如何决定继续人工复核、阻断或放行。
- **Ontology（本体/概念表）**：把不同语言的表达映射到相同推理概念的明确词表。
- **Clean near-neighbour（干净近邻）**：与受保护案例主题相近，但不存在内容血缘的独立负例。

## 2. Generic repair

`s5_lineage_detector_v081.py` preserves v0.7.3 and adds:

1. a small inspectable English/Chinese/Japanese/Spanish reasoning ontology covering evidence gaps, audit/adjudication,
   protocol deviation, rescue intervention, causal attribution, efficacy and uncertainty;
2. protected-exclusive hyphenated identifier matching, excluding shared underscored rubric labels;
3. cross-language identifier/concept agreement for translated derivatives;
4. multi-reference aggregation when one candidate has dense protected-exclusive evidence from at
   least two protected cases;
5. stricter evidence requirements for `REVIEW`, preventing generic same-domain vocabulary and a
   single shared scoring field from escalating a clean record.

A blanket `REVIEW → BLOCK` conversion was deliberately not used because v0.8 had already shown a
clean English case entering review.
