# S2 v0.2 Evaluation Report

> **S2 = Stage 2, Knowledge Search & Source Routing（知识搜索与来源路由）**  
> Date: 2026-09-05  
> Status: **PARTIAL PASS — routing generalization not yet release-ready**

## Terminology

- **held-out（留出集）**：开发/调参时不参与规则修改的数据，用来测泛化。
- **shadow held-out（影子留出集）**：在一次调试周期结束后新建、首次运行前不查看结果的新留出集，用来防止“对留出集继续调参”。
- **regression（回归测试）**：系统修改后重复运行已经冻结的测试，确保旧能力没有被破坏。
- **API = Application Programming Interface（应用程序编程接口）**：程序直接访问外部数据库/服务的标准接口。
- **DOI = Digital Object Identifier（数字对象唯一标识符）**：论文等数字对象的稳定唯一标识。
- **PMID = PubMed Identifier（PubMed 文献唯一编号）**。
- **FAERS = FDA Adverse Event Reporting System（美国食品药品监督管理局不良事件报告系统）**。
- **DDI = Drug–Drug Interaction（药物-药物相互作用）**。
- **QTc = corrected QT interval（校正后的 QT 间期）**，用于心脏复极/心律失常风险相关评价。
- **LOINC = Logical Observation Identifiers Names and Codes（检验与临床观察标准编码体系）**。
- **RxNorm（美国国家医学图书馆临床药物标准术语系统）**：用于品牌名、通用名、成分和剂型等药物概念标准化。

# 1. What S2 v0.2 evaluates

S2 is intentionally split into two independently observable components:

```text
User information need
        ↓
S2A Source Routing
        ↓
which authoritative source family should be queried?
        ↓
S2B Live Retrieval
        ↓
can the system retrieve the expected authoritative record from the real source?
```

S2 v0.2 still does **not** prove passage-level evidence retrieval. Critical-passage retrieval belongs to the next substage.

40 frozen queries.

```text
Primary Source Recall@1       1.000
Acceptable Source Recall@3    1.000
Source Type Accuracy          1.000
Freshness Routing Accuracy    1.000
Wrong Authority Rate          0.000
Secondary-as-Gold Rate        0.000
Critical Source Miss Rate     0.000
```

This set is a **regression set**, not evidence of arbitrary-query generalization.

## 2.2 First v0.2 held-out run before bilingual/source-policy redesign

30 unseen Chinese/English/mixed-intent queries were run using the previous router.

```text
Primary Source Recall@1       0.367
Acceptable Source Recall@3    0.467
Source Type Accuracy          0.433
Freshness Routing Accuracy    0.435
Wrong Authority Rate          0.567
Secondary-as-Gold Rate        0.133
Critical Source Miss Rate     0.556
```

This revealed that the 100% v0.1 result had poor generalization.

### Root causes

- Chinese/colloquial intent coverage was weak;
- generic fallbacks fired too early;
- approval vs trial-registry intent was not separated robustly;
- general DDI-methodology queries were confused with DDI lookup tables;
- multi-source information needs were not decomposed;
- some evaluator assumptions were too restrictive.

## 2.3 v0.2 diagnostic fixes

The router was redesigned around bilingual intent families + source policy rather than only narrow individual keywords.

The same 30-query set later reached 100%, but because its failures had already been inspected, it was **promoted to a regression set** and is no longer called a true held-out set.

# 3. Fresh shadow held-out v0.2b

A new 15-query shadow-heldout set was created after v0.2 fixes and was not used to tune the router before the first recorded run.

Result with `deterministic-s2-v0.2.1`:

```text
Primary Source Recall@1       0.733
Acceptable Source Recall@3    0.800
Source Type Accuracy          0.733
Freshness Routing Accuracy    0.833
Wrong Authority Rate          0.267
Secondary-as-Gold Rate        0.267
Critical Source Miss Rate     0.000
Release Gate                  FAIL
```

### Untouched failures

1. **S2SH-004 — LOINC observation normalization**
   - Query asked for a standard observation code for urine albumin/creatinine ratio.
   - Router fell back to PubMed.
   - Failure: terminology/normalization intent not recognized from a new Chinese phrasing.

2. **S2SH-006 — general DDI methodology**
   - Query asked for transporter-mediated drug-interaction study design principles.
   - Router ranked FDA DDI tables above FDA/ICH M12.
   - Failure: mechanism lookup vs methodology distinction remains brittle.

3. **S2SH-008 — FAERS signal lookup**
   - Query described the FDA spontaneous adverse-event system without using the literal token `FAERS`.
   - Router fell back to PubMed.
   - Failure: concept-level intent recognition is still too dependent on lexical triggers.

4. **S2SH-014 — QTc labeling guidance**
   - Query asked for current FDA general QTc labeling guidance using a different phrasing.
   - Router fell back to PubMed.
   - Failure: guidance-intent paraphrase robustness is insufficient.

### Interpretation

The router is currently good at **known routing patterns**, but the shadow set shows that a keyword-oriented deterministic router is not yet robust enough for open-ended medical user language.

This shadow result is frozen and must not be overwritten by a post-hoc tuned score.

# 6. Recommended engineering change

Do **not** keep adding literal keywords until the shadow set becomes 100%.

The next router should separate:

```text
Query
 ↓
Intent representation
 ↓
clinical/regulatory/terminology/signal/methodology intent
 ↓
source policy table
 ↓
ranked source families
```

Candidate implementation options:

1. rule-based semantic feature layer as an interpretable baseline;
2. embedding/classifier-based intent router with deterministic source-policy constraints;
3. small LLM intent classifier whose output is restricted to a closed source-intent schema;
4. hybrid: deterministic hard safety/jurisdiction rules + learned intent classifier.

Whichever implementation is chosen, it must be evaluated on a **new fresh held-out set**, not by repeatedly tuning the current shadow set.

# 7. Next S2 milestone

```text
S2 v0.3
├── intent-router redesign
├── new untouched routing held-out set
├── current-version / canonical-document selection eval
└── critical-passage Recall@K eval
```

**Recall@K（前 K 个检索结果中的召回率）** will measure whether the required source/passage appears within the first K returned candidates.

Only after these pass should S2 be marked `READY_FOR_DOWNSTREAM_TRUTH_PIPELINE`.
