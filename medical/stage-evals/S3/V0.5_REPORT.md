## Root-cause taxonomy after first run

The failure pattern is narrower than v0.3/v0.4 and now concentrates in five structural classes:

1. `NEGATION_POLARITY_ERROR` — explicit `not contraindicated` can still be read as positive contraindication;
2. `BOUNDARY_NEGATION_NORMALIZATION` — statements such as `not automatic discontinuation` or `does not establish endpoint achievement` are bounded evidence summaries, not unsupported dangerous extensions;
3. `MISSING_EXTENSION_PROPOSITION` — subgroup or endpoint-success additions are omitted from candidate decomposition, causing false DIRECT_SUPPORT;
4. `MUTUALLY_EXCLUSIVE_OBJECT_POLARITY` — benign vs malignant values need explicit contradiction semantics;
5. `PREDICATE_COVERAGE_GAP` — incidence, subgroup comparison and some signal/causality paraphrases are not normalized into stable predicates.

## Decision

## Required v0.5.3 changes

- explicit scope-aware negation for `NOT_CONTRAINDICATED`;
- normalize bounded negative summaries such as `not automatic discontinuation` and `endpoint not established`;
- extract unsupported extensions as independent propositions;
- add mutually-exclusive categorical contradiction rules;
- expand proposition coverage for incidence, subgroup comparison, endpoint achievement and signal/causality bounded claims;
- keep unresolved high-risk claims conservative: never promote to `DIRECT_SUPPORT`.
