## Broader failure pattern

The most important observation is not an isolated predicate bug. Many failures contain:

```text
no_candidate_propositions
unsupported=...
```

or fail because a previously unseen paraphrase is not mapped to the canonical proposition type.

Representative misses include:

- `less than 30` / `not-recommended interval` renal phrasing;
- bounded reassessment-vs-discontinuation wording;
- spontaneous-report signal detection with `cannot distinguish causation from association`;
- `no complete denominator` / `cannot yield event rate` incidence language;
- ACTIVE, NOT RECRUITING registry status and bounded outcome statements;
- `replaces ... as the operative recommendation source` guideline supersession;
- postdating trial vs unchanged operative guideline;
- explicit benign/malignant categorical conflict;
- subgroup comparison extensions;
- explicit `not associated` vs absence of association analysis.

## Architectural diagnosis

The v0.6 result shows that S3 currently conflates two different capabilities:

```text
S3a: Free-text Semantic Proposition Extraction
     evidence / claim text
     → canonical atomic propositions

S3b: Deterministic Proposition Entailment
     proposition set + conditions + polarity + temporal state
     → support / contradiction / partial / unsupported
```

The exposed regression suites increasingly test S3b after their language has influenced the parser. The v0.6 fresh set primarily breaks S3a: unseen paraphrases fail to produce the correct propositions, after which the deterministic truth logic cannot recover.

Therefore continuing to add item-specific lexical rules would overfit the parser and would not constitute evidence that S3 generalizes.

## Decision

S3 remains **FAIL and is not eligible for automatic KG truth insertion**.

The next redesign should explicitly separate extraction quality from entailment quality:

1. build an S3a proposition-extraction evaluation with gold proposition frames and critical-proposition recall;
2. build an S3b proposition-level entailment evaluation where gold structured propositions are supplied directly, isolating threshold algebra, polarity, scope, temporal direction and aggregation;
3. only then evaluate the end-to-end free-text S3 pipeline again on a new untouched set.

The v0.6 set is now exposed and may only be used as diagnostic/regression evidence after this first run.
